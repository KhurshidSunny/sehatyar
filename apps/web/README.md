# SehatYar web app

Progressive web app for FAQ browsing and medicine lookup.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

## Local development

Scaffolding and run instructions will live here once the web app is initialized.

```bash
# from apps/web (after package setup)
npm install
npm run dev
```

## Notes

- UI targets low-literacy use: large tap targets, short Pashto copy, audio playback.
- Offline caching of top FAQs and audio is part of the product design.
- The app must show a clear non-prescribing disclaimer on main flows.
